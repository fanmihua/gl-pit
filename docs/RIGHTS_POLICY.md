# glfans 内容权利与素材管理

## 页面如何展示

- 全站页尾只显示一句短声明和“权利说明与反馈”入口，避免长文打断阅读。
- “关于”页面使用折叠区承载完整声明；从页尾进入时自动展开。
- Repo 正文、表情包和电台只显示与当前内容有关的一句提示，不重复整份声明。
- `© glfans` 仅指网站原创文字、设计与代码，不涵盖艺人肖像、剧照、海报、音视频或其他第三方素材。

## 素材状态

- `source-audit-required`：需要继续核对原始来源、权利主体与使用边界。默认不提供下载；无法确认时应更换或下架。
- `external-stream-only`：只调用平台提供的外部音频地址并保留歌曲页面入口，不下载、不转存、不自行托管。
- 新增素材必须先进入 `docs/media-rights-inventory.json`，再进入公开页面。
- 仓库不是“一份许可证包全部内容”：代码、原创内容与第三方素材的边界以根目录 `LICENSE` 和 `NOTICE` 为准。

运行 `npm run rights:inventory` 可从当前 Repo 内容重新生成图片清单。自动清单只能帮助发现素材，不能替代人工核权。

## 处理流程

1. 记录素材所在页面、原始来源、权利主体、用途和当前状态。
2. 优先使用官方宣传素材、自有原创、明确授权或官方可嵌入内容。
3. 评论引用只保留表达观点所必需的画面，并在页面中标注用途与权利归属。
4. 来源不明、争议明显或被权利人提出异议时，先隐藏或断开链接，再核验处理。
5. 公开反馈只收集具体页面、具体内容和处理诉求；身份证明等敏感材料转为非公开沟通。

## 当前边界

- 表情包池包含第三方画面，站内仅作展示，不提供下载。
- 坑底电台只接入网易云歌单中当前明确可播放的 12 首外部音源，并保留完整歌单与单曲页面入口；不嵌入第三方播放器界面。
- 不提供完整剧集、完整音视频、破解资源、付费内容转载，也不利用艺人肖像暗示代言、合作或商品销售。
